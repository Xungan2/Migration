# 统一迁移准备

P0 与 P1 的执行组织已合并。当前入口、续跑方式和结果见 [README](../README.md)，
详细需求见[统一 P0/P1 规格](specs/unify-p01.md)。

主 agent 按需派发子任务并独自验收骨架构建/载入和迁移规划；任务不继续派发。
当前宿主按顺序调用任务，保证单一代码写入者。专门的知识 agent 通过 opencode 会话续接，
在新交接或决策到达后整理共享知识；没有新输入时不调用。知识冲突带证据交主 agent 决定。

知识按源端、目标集成、环境、构建、载入、测试、规划主题建目录。内部结构自主决定，
每个已创建主题有 README 入口。AUTO 三文档与 verification 保留当前总览。
子任务按需读取相关 handoff 和知识入口；历史 handoff 不改写，知识移动后旧路径留跳转。

只有两项验收均通过、知识已更新且主 agent 确认完成时才返回整体成功。
默认不要求完整业务功能或单测通过；用户明确的本阶段特殊要求仍必须满足。
未完成项记录到 AUTO 文档，阻塞与中断保留现场。旧阶段和 runner 协议已退出本分支执行路径。
