# knowledge/pitfalls/ — 跨驱动踩坑知识

迁移中实证的**平台/模拟器级**坑（非驱动自身 bug）。条目 = 一个可复用的
结论 + 实证证据。规则与 maps 域同源：源码为准、不跨驱动复用未验证结论、
同名 = 版本更新。

INDEX.json 为机器索引；条目文件 = `<id>.md`。

## 适用判据

一条 pitfall 记录应满足：换一个驱动迁移到同一目标 OS/模拟器组合时，
**大概率再次撞上**且**撞上时代价高**（半路停车/长时间排查）。
