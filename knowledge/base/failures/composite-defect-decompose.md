# 复合缺陷分解法（composite-defect-decompose）

**签名**：单变量排查各自"部分有效"（改一处缓解一点但都不除根），
多症状并存且似有关联。

**判别**：假设"多个独立缺陷叠加"——把表象分解为独立证据链，
逐条验证各自的存在性（A 真、B 真、C 真 → 三条独立缺陷而非一个
复合根因）。

**归责**：migration（复合）

**建议动作**：`fix-code` ——逐条清偿、逐条双信号复验，**勿一次
性大改**（大改后好坏变化混在一起无法归因）。清单化管理各条状态。

**实证**：RX-PATH 三重叠加（configure_rx 未接线 + watchdog 无
调用方 + 模拟器行为差异；首现代价 ~2h——其中大半耗在"当作单一
根因反复单变量试"）。
