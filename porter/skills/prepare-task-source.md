# 源码与依赖调查

围绕给定目标调查到足以支持骨架或规划交付；已知证据通过 inputs 和相关知识入口复用。

1. 从源驱动注册、匹配和初始化入口追踪主要调用链、数据与状态、错误和退出恢复语义。
   给出入口和关键分支的源码证据，区分目录内迁移文件与目录外依赖。
2. 查目标 OS 对应的原生接口、初始化机制及先例。构建先例只证明接线方式，设备先例还需
   对应控制器、匹配条件和适用环境，不能互相替代。
3. 列最小能力依赖关系，为每项标记 available、missing 或 unknown，附源/目标证据、影响、
   所需补齐工作或待确认条件。遵守用户迁移范围，未知硬件不默认缩减厂商或设备范围。
4. 交付职责、源码归属、关键行为、依赖与目标接入结论。证据已足够支持指定决策即停止；
   不为清空 unknown 扩大调查，不在本任务实现骨架或开展未派发的验证。
